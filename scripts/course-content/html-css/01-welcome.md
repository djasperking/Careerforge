## 👋 Welcome, future web developer!

Hi, I'm Daniel — your instructor. In this course you're going to build **real websites from scratch**, even if you've never written a line of code in your life.

No jargon walls. No boring theory dumps. Every idea comes with a **live code box** you can edit, break, fix and play with.

### What you'll build

- 🏗️ A personal **About Me** page, using HTML
- 🎨 A beautifully **styled** version, using CSS
- 🚀 A **responsive landing page** that looks great on phones *and* laptops (your final project)

### How the course works

1. **Read** a short lesson (5–8 minutes).
2. **Play** with the live code boxes — they're real code. Edit anything!
3. **Check yourself** with friendly quizzes.
4. **Build** 3 hands-on assignments.
5. **Take the final exam** and earn your certificate 🎓

### What you need on your computer

Only two things:

- A web browser (Chrome, Edge, Firefox, Safari — whatever you already use)
- A text editor. Notepad works! **VS Code** (free) is nicer because it colours your code.

You'll start using them for your assignments in Module 2. For now, the code boxes in the lessons are all you need.
